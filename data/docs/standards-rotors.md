A replacement rotor has to match the hub's mount and the size the caliper is set up for.

## 6-bolt vs Center Lock

Rotors mount to the hub either with six bolts (6-bolt) or a splined Center Lock interface with a lockring. A rotor has to match the hub's mount. Adapters exist to run a 6-bolt rotor on a Center Lock hub, but that's a mechanic's call, not a counter quote.

## Rotor size matches the caliper setup

The caliper sits on an adapter set for one rotor size. Replacing a rotor means matching the size that's on there now, front and rear separately: many bikes run a bigger rotor in front (for example 203 mm front, 180 mm rear). Changing size needs a different caliper adapter and is an upgrade a mechanic quotes.

## Shimano 203 mm vs SRAM 200 mm

Shimano's large rotors are 203 mm; SRAM's are 200 mm. They aren't interchangeable: the 3 mm difference changes where the caliper sits, and the wrong one can rub or brake on only part of the pad. Replace a 203 with a 203 and a 200 with a 200 unless a mechanic changes the adapter.

## When to replace a rotor

Rotors wear thinner over time. Most have a minimum thickness stamped on them, around 1.5 mm for a 1.8 mm rotor. A warped rotor can sometimes be trued (`ROTOR-TRUE`). A rotor contaminated with oil usually needs replacing along with the pads.
